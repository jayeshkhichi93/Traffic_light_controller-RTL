# Traffic Light Controller (RTL Design)

This project implements a fully functional 4-state Traffic Light Controller using a Finite State Machine (FSM) in Verilog.
It efficiently manages timer-based state transitions for North-South and East-West intersections.

## 🚦 FSM State Logic
The controller transitions between 4 main states based on an internal timer:
* **S0 (NS Green, EW Red):** Stays for 11 clock cycles.
* **S1 (NS Yellow, EW Red):** Stays for 4 clock cycles.
* **S2 (NS Red, EW Green):** Stays for 11 clock cycles.
* **S3 (NS Red, EW Yellow):** Stays for 4 clock cycles.

## 🛠️ Tools Used
* **Language:** Verilog HDL
* **Simulation:** Icarus Verilog (`iverilog`)
* **Waveform Viewer:** GTKWave

## 🚀 How to Run the Simulation
To compile and run this project on your local machine, use the following commands in your terminal:
```bash
iverilog -o tlc_sim tlc.v tlc_tb.v
vvp tlc_sim
gtkwave tlc.vcd &
